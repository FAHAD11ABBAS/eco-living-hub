# Eco Living Hub

This is my school project. It is a single page app made with React. It help to track green habits every day and calculate carbon and money save.

## What it do (Features)
- **Eco Habits:** Can click and check daily green actions (like walk, save energy).
- **Eco Calculator:** Put numbers to see how much CO2 and money save.
- **Dark / Light Mode:** Change theme color.
- **Language Switch:** Can change text to English or Finnish (Suomi).
- **Progress Bar:** See progress go up when finish habits.

## Tools I use
- React (components, useState)
- CSS
- Vite
- GitHub Pages

## How to run on PC
1. Clone repo:
   git clone https://github.com/FAHAD11ABBAS/eco-living-hub.git
2. Install:
   npm install
3. Run:
   npm run dev
